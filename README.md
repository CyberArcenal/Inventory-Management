# Lite Management System

A lightweight, capstone-ready application designed for students and small businesses.  
Built with **Node.js + Electron + SQLite**, this system focuses on simplicity, audit safety, and rapid deployment.

## ✨ Features
- **User-friendly interface** – minimal screens, easy navigation
- **Core CRUD operations** – reliable data entry and retrieval
- **Audit-safe logging** – every transaction recorded for clarity
- **Export options** – generate CSV/PDF reports
- **Lite footprint** – runs smoothly on low-spec machines

## 📦 Installation
1. Download the installer from the release section.
2. Run the setup file and follow the instructions.
3. Launch the app from your desktop.

## 🛠 Tech Stack
- **Frontend:** Electron
- **Backend:** Node.js
- **Database:** SQLite (local, lightweight)
- **Packaging:** Electron Builder

## 🚀 Usage
1. Log in with your account.
2. Perform CRUD operations (add, edit, delete, view).
3. Generate reports from the dashboard.
4. Optional: connect to central DB for multi-branch sync.
