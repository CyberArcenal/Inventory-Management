# User Guide

## 📦 Installation
1. Download the installer file from the provided link.
2. Run the installer and follow the on-screen instructions.
3. After installation, launch the application from your desktop.

## 🔑 Login
- Default admin account:
  - **Username:** admin
  - **Password:** admin
- You can change the password in the settings menu.

## 🚀 Basic Usage
1. **Dashboard**  
   - View system overview and quick stats.
2. **Records Management (CRUD)**  
   - Add new entries (students, books, patients, grades).  
   - Edit or delete existing records.  
   - Search and filter data easily.
3. **Reports**  
   - Generate daily/weekly summaries.  
   - Export reports to PDF or CSV.

## ⚙️ Settings
- Update account credentials.  
- Configure system preferences (e.g., themes, auto‑backup).  
- Optional: connect to central database for multi‑branch use.

## 🛠 Troubleshooting
- **App won’t open:** Reinstall the application and check if your system meets requirements.  
- **Data not saving:** Ensure database file is not read‑only.  
- **Forgot password:** Contact admin or reset via settings file.

## 📖 Notes
- This is a **Lite version**: focused on core features only.  
- For extended features (multi‑user, advanced reporting, licensing), upgrade to the **Pro version**.
